# Documentos de fase

Un documento por fase terminada que explica **por qué** se hizo así, no solo **qué** se hizo:

- los conceptos, desde cero;
- cómo funciona en este repositorio;
- cómo se comprueba;
- qué salió mal;
- cómo defenderlo en una entrevista.

| Documento | Para qué sirve |
|---|---|
| [`SCOPE.md`](../../SCOPE.md) | **Fuente de verdad** de qué se hace, con fases, casillas, decisiones y registro de cambios |
| `docs/fases/fase-N.md` (este directorio) | La explicación de cada fase: porqué, conceptos, funcionamiento, comprobación y lecciones |
| [`docs/adr/`](../adr/README.md) | Una página por decisión de arquitectura (D1–D9), en formato breve |

Si algo de aquí contradice a `SCOPE.md`, manda `SCOPE.md` y este documento está desfasado.

Cada documento se escribe al cerrar su fase, con el visto bueno de Sofía. Va en español.
