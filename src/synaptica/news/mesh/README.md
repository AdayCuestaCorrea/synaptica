# MeSH branches of the topics

Descriptors and entry terms of each MeSH tree used by `synaptica.news.topics`, from the
NLM MeSH SPARQL endpoint (`id.nlm.nih.gov/mesh/sparql`), copied from the mock-up cache
`spikes/web/data/sources/mesh/` (downloaded 2026-11-12). MeSH is free to use, courtesy of
the U.S. National Library of Medicine. The root descriptor of each branch (Sleep, Memory…)
was missing from that cache and was added on 2026-11-13 (the spike filtered the tree label,
not the tree IRI). The Emotion branch (F01.470) is left out until
Sofía confirms that topic (SCOPE v13 and v118).
