# MeSH descriptors of the brain

Every descriptor under tree number A08.186.211 (Brain), with each of its tree numbers and entry
terms, from the NLM MeSH SPARQL endpoint (`id.nlm.nih.gov/mesh/sparql`), written by
`syn atlas mesh` (by hand, never in the pipeline; first fetched on 2026-11-16: 196 descriptors).
`synaptica.atlas.studies` uses it with `../region_terms.toml` to match studies to the rat ↔ human
pairs of Neuro Atlas. MeSH is free to use, courtesy of the U.S. National Library of Medicine.
